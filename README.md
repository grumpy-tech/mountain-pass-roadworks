# Mountain Pass Roadworks

I want to make a 2d top down construction game - projects like building a road for example. moving dirt and clearing the path then making the road. I want to add some challenge to the game like a winding road through a mountain pass or something. Want the game to look polygon style. Maybe 3d but from a angled view. I want simple controls and to kinda have a snowrunner feel
